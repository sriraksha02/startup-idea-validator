# 🚀 AI Startup Idea Validator

An AI-powered web application that evaluates startup ideas using Natural Language Processing.

## 🔍 Features
- Idea similarity analysis using TF-IDF and cosine similarity  
- Uniqueness scoring system  
- SQLite database integration  
- CSV download functionality  
- Interactive UI using Streamlit  

## 🛠 Tech Stack
- Python  
- Streamlit  
- Scikit-learn  
- SQLite  
- Pandas
